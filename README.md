Dungeon Dash

A grid-based 2D game developed using C++ in combination with the SFML (Simple and Fast Multimedia Library)

Features

- Player can move freely across the map using keyboard controls.
- Enemies use simple AI logic to chase the player.
- Health system allows players to collect potions and restore health.
- Strategic gameplay elements are included through health management.
- Scoring system tracks the number of enemies defeated.
- Multiple game states are implemented, including:
       - Menu screen
       - Gameplay screen
       - Win screen
       - Lose screen
- Provides an interactive and engaging gaming experience.

Technologies Used

- C++
- SFML Library

How to Run the Project

- Install a C++ compiler such as GCC.
- Install a development environment like Visual Studio Code.
- Download and set up the SFML (Simple and Fast Multimedia Library).
- Configure SFML libraries and dependencies properly.
- Ensure the system has at least:
       - Intel i3 processor or equivalent
       - 4GB RAM
- Use either Windows or Linux operating system.
- Compile the C++ source code using the compiler.
- Run the generated executable file to start the game.
